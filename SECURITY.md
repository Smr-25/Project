# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through GitHub's security advisory feature for this repository and include the affected version, reproduction steps, impact and any suggested mitigation.

Do not include real credentials, customer information or production data in the report.

## Supported versions

Security fixes are applied to the latest version on the default branch. This portfolio project does not currently maintain parallel long-term-support release branches.

## Deployment responsibility

The included Compose stack is intended for local evaluation. Anyone deploying the application is responsible for TLS, secret storage, network controls, database backups, encrypted Data Protection key storage, monitoring and dependency update review in that environment.
